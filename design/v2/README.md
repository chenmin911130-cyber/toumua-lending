# Toumu’a V2 设计与 Cursor 交付包

本版补齐剩余页面及交互规范：**42张高保真页面／状态图、196项交互定义**。保留V1。当前完成的是设计，业务代码与应用测试尚未实施。

## 阅读入口

1. `index.html`：设计册，按分组/编号浏览、放大、记录和导出意见。
2. `implementation.html`：可搜索的逐按钮实现清单，按页面查看权限、校验、行为和验收。
3. `CURSOR_HANDOFF.md`：可直接复制给Cursor的任务，及模块交付顺序。
4. `IMPLEMENTATION_SPEC.md`：路由、字段、权限、状态机、API目标契约、逻辑数据模型和三端约定。
5. `BUTTON_FUNCTIONS.md` / `controls.json` / `controls.csv`：相同196项定义的阅读／机器／表格版本。
6. `ACCEPTANCE_TESTS.md`：逐控件及跨模块测试计划，全部待执行。
7. `DECISIONS.md`：已定设计和外部依赖，不把未知利率与现有schema伪装成已知。
8. `DESIGN_SPEC.md`：视觉规范、页面和复用状态说明；`manifest.json`保留完整图像提示词及来源。

## 本机预览

在此目录执行 `python3 -m http.server 7211 --bind 127.0.0.1`，打开 `http://127.0.0.1:7211/`。评审意见保存在当前浏览器的localStorage，不自动同步到Cursor；使用“导出修改意见”交付。V1和V2使用相同存储键，但不同端口属于不同来源；V1原意见保持原地，不会自动迁移。

Cursor开始实现后，将controls.json每项的实现状态和代码/测试路径更新为有证据的实际情况。不要重跑build_controls.py覆盖已填进度。图片索引与原始设计状态都不是功能完成证明。
